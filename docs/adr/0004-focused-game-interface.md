# Focused game interface

Guesshin uses a focused play surface instead of a dashboard-like collection of decorative panels. The interface uses one system sans-serif family, a small spacing scale, a restrained dark palette with gold as the brand accent, and a compact tutorial and terminal Reveal; circular loaders provide local feedback for Game creation, response generation, and terminal actions. The favicon uses an original constellation or star mark rather than copied character artwork, preserving the project's original-visuals constraint.

## Considered Options

- Decorative gradients, blur, multiple typefaces, and large status panels: rejected because they compete with the dialogue and create inconsistent visual hierarchy.
- A Paimon or other character favicon: rejected because it introduces copied character artwork and conflicts with the original visual identity constraint.
- Full-page loading overlays: rejected because they hide the Game context; loading feedback stays next to the action in progress.
